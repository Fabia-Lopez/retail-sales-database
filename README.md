
# Retail Sales Database


This project is a relational database designed to manage a small retail store's customers, products, orders, and sales data.

It demonstrates basic database design, SQL queries, table relationships, and sales analysis.

-Database Structure

The database contains four tables:

- **Customers:** Stores customer information.
- **Products:** Stores product names, categories, and prices.
- **Orders:** Stores customer orders and order dates.
- **OrderDetails:** Stores the products and quantities included in each order.

## Skills Demonstrated

- SQL queries using SELECT, WHERE, and ORDER BY.
- Relational data using INNER JOIN.
- Aggregate functions such as SUM() and COUNT().
- Data grouping using GROUP BY.
- Sales calculations and customer spending analysis.
- Primary keys, foreign keys, and data integrity constraints.

## Project Files

- `retail_sales.db` — SQLite database file.
- `queries/01_basic_queries.sql` — Basic queries and filtering.
- `queries/02_joins.sql` — Queries using table relationships.
- `queries/03_sales_analysis.sql` — Sales calculations and analysis.
